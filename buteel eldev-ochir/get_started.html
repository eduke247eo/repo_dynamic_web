Get started

Learn the basics of crochet and start your journey into the world of crochet.

To start crocheting, you’ll need:

  • Crochet hook – A medium size like 5mm is great for beginners.
  • Yarn – Use medium-weight yarn in a light color so you can see your stitches.
  • Scissors – For cutting yarn cleanly.
  • Yarn needle – Used to weave in the ends when finishing.
  • Stitch markers (optional) – Help track your place in the pattern.

That's it! With these basics, you're ready to start your first crochet project. All of these could be easily obtained via amazon etc.
